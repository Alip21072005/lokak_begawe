# 💼 Lokak Begawe — Solusi Kerja Wargo Bengkulu

**Lokak Begawe** adalah platform pencarian kerja digital yang didesain khusus untuk menghubungkan talenta terbaik di Provinsi Bengkulu dengan peluang karir impian mereka. Proyek ini dibangun dengan semangat untuk memajukan ekonomi lokal melalui teknologi yang inklusif dan mudah digunakan.

---

### 🌟 Visi Proyek

Menjadi jembatan utama antara pencari kerja dan penyedia lapangan kerja di seluruh pelosok Provinsi Bengkulu, mulai dari pesisir hingga pegunungan.

---

### 🚀 Persiapan Awal

Sebelum memulai petualanganmu mengembangkan **Lokak Begawe**, pastikan perangkatmu sudah terinstal:

- **PHP** (Versi 8.1 ke atas)
- **Composer** (Manajer paket PHP)
- **Node.js & NPM** (Untuk keajaiban tampilan frontend)
- **Database** (MySQL atau MariaDB)

---

### 🛠️ Langkah Instalasi

Ikuti langkah-langkah berikut untuk menjalankan proyek di perangkat lokalmu:

1.  **Clone Repositori**
    Ambil salinan kode proyek ke komputermu:

```bash

    git clone [https://github.com/aranustech/cdc-perseverance.git]
    cd cdc-perseverance
```

2.  **Instalasi Dependensi**
    Siapkan semua modul yang diperlukan agar aplikasi berjalan lancar:

```bash
    composer install
    npm install && npm run dev
```

3.  **Konfigurasi Lingkungan (Environment)**
    Salin template konfigurasi dan sesuaikan pengaturan databasemu:

```bash
       cp .env.example .env
```

Tips: Buka file .env dan pastikan bagian DB_DATABASE, DB_USERNAME, dan DB_PASSWORD sudah sesuai dengan database lokalmu.
